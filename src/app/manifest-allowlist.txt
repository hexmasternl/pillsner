# The permissions Pillsner ships, and nothing else.
#
# This file is the disclosed contract for the app's merged manifest (medicine-label-photo-prefill
# design D7, D8). The build task verifyManifestGuard<Variant> compares every variant's merged
# manifest against it after manifest processing and fails the build when the two differ in either
# direction, naming each offending permission. It runs as part of check, assemble<Variant> and
# bundle<Variant>, so CI and the release workflow both run it.
#
# Every line here is a deliberate choice that the README's permission table explains. Adding a
# line is a product decision that goes through an OpenSpec change; never add one to make a build
# pass. Comments start with '#'. One permission per line, by its full name.

# --- Contributed by libraries through manifest merging ----------------------------------------
# androidx.biometric: the app lock's biometric unlock (app-login). Normal-level, granted at install.
android.permission.USE_BIOMETRIC
android.permission.USE_FINGERPRINT
# androidx.work: the alarm watchdog (reminder-delivery-reliability D3). Normal-level. WorkManager
# reads the network state for its own constraint machinery; Pillsner never declares INTERNET and
# never opens a connection, so knowing whether the network is up gives it nothing to do with it.
android.permission.WAKE_LOCK
android.permission.ACCESS_NETWORK_STATE
# androidx.core: a signature-level permission the app defines for itself so its runtime-registered
# receivers are not exported. Only this app's own signature can hold it.
nl.hexmaster.pillsner.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION
